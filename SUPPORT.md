# Support

For help with a Mara public repository:

- Use the repository README first.
- Search existing issues before opening a new one.
- Open a bug report for reproducible defects.
- Open a feature request for product or API improvements.
- Open a docs issue for unclear or missing documentation.
- Join the bilingual [Mara Community on Discord](https://discord.gg/j7pastrgTf) for general
  product help, release updates, and conversations with users and builders.

For private or account-specific product help, contact `support@iammara.com`. For business and
partnership questions, contact `contact@iammara.com`. Report security issues privately to
`security@iammara.com`.

Do not post secrets, real customer data, private logs, access tokens, API keys, or real personal data
in public issues or pull requests.
